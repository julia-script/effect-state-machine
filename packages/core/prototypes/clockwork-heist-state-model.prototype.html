Heist

Drive a tiny turn-based museum escape and watch every accepted, rejected, automatic, and child-like transition appear in the machine lens beside it.

Question: can a compact heist produce a legible range of semantic events and transitions—guards, retries, cancellation, completion, and protocol rejection—without turning the state machine into a rendering loop? This page tests the domain model only; it is not wired to the real library or Studio transport yet.
