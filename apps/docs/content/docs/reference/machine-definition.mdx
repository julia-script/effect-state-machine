---
title: Machine definition API
description: Technical reference for schemas, builders, nodes, transitions, and definitions.
---

The `Machine` namespace is exported from `effect-state-machine` and from the
`effect-state-machine/Machine` subpath.

```ts
import * as Machine from "effect-state-machine/Machine"
```

## `Machine.taggedUnion`

```ts
Machine.taggedUnion(cases)
```

Builds an Effect `Schema.TaggedUnion` discriminated by `_tag`.

| Parameter | Type | Description |
| --- | --- | --- |
| `cases` | `Readonly<Record<string, TaggedUnionCase>>` | Map from tag to fields and optional annotations. |

Each case accepts `fields`, optional `title`, and optional `description`. Titles and descriptions
become Schema annotations and are retained by graph tooling. The return value is an ordinary Effect
Schema and exposes tagged-union `cases`.

```ts
const State = Machine.taggedUnion({
  Idle: { fields: {}, description: "Wait for work." },
  Active: { fields: { id: Schema.String }, title: "In progress" },
})
```

`Machine.builder` also accepts an existing `Schema.TaggedUnion` or a `Schema.Union` of tagged
structs. Ordinary unions are normalized with `Schema.toTaggedUnion("_tag")`.

## `Machine.namedGuard`

```ts
Machine.namedGuard({ name, description?, guard })
```

Returns a `NamedGuard<Args>` and captures its declaration source for development tooling.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Stable authored guard name. |
| `description` | `string | undefined` | Optional human-readable metadata. |
| `guard` | `(args: Args) => boolean` | Synchronous decision function. |

`builder().guard` is the same function.

## `Machine.builder`

```ts
Machine.builder({ input, state, event })
```

Binds the machine's three schemas and returns schema-narrowed definition constructors.

| Field | Constraint |
| --- | --- |
| `input` | Any Effect Schema. |
| `state` | Tagged union or union of `_tag`-discriminated tagged structs. |
| `event` | Tagged union or union of `_tag`-discriminated tagged structs. |

The returned object contains `define`, `state`, `invoke`, `regions`, `region.invoke`, `child`,
`final`, and `guard`. Constructors are tagless: the key passed to `define` supplies the current-state
tag and inference scope.

### `state(on, options?)`

Creates an ordinary state node.

| Parameter | Description |
| --- | --- |
| `on` | Partial event-handler record narrowed to the keyed current state. |
| `options.description` | Optional authored metadata. |
| `options.after` | Optional entry-owned timer transition. |

### `invoke(config, on?, options?)`

Creates a state node that owns one Effect while active.

| Field | Description |
| --- | --- |
| `name` | Required stable invocation name. |
| `description` | Optional authored metadata. |
| `effect` | Receives the state narrowed by the definition key and returns the invoked Effect. |
| `retry` | Optional named `RetryPolicy` containing an Effect `Schedule`. |
| `onSuccess` | Transition or guarded outcome for the Effect value. |
| `onFailure` | Transition or guarded outcome for the Effect or Schedule typed error. |
| `on` | Optional second-argument event handlers accepted while work is active. |
| `options.after` | Optional third-argument entry-owned timer transition. |

### `invoke.all(config, on?, options?)`

Creates an invoked node that joins a keyed `tasks` record. A task is an Effect-producing function or
an object containing `effect` and optional `description`. `onSuccess` receives a result record keyed
by every lane. `concurrency` is a positive integer or `"unbounded"` and defaults to `"unbounded"`.

### `invoke.race(config, on?, options?)`

Creates an invoked node that selects the first successful task. `onSuccess` receives correlated
`winner` and `value` fields. Typed lane failures remain pending while another lane can succeed;
`onFailure` runs after every lane has failed.

### `regions(trees, on?, options?)`

Creates a region-bearing state. `trees` is keyed by tagged-union fields on the parent state; every
slot contains exactly one node for every tag in that field's union. One slot is compound and several
slots are parallel. `on` contains parent fallback handlers. `options.onComplete` is selected when
every active slot child is final.

Region event reducers receive `state`, `event`, and the read-only narrowed `parent`. Targets are
restricted to tags in the same slot. `region.invoke(config, on?, options?)` declares one Effect
owned by a region child; its Effect receives the child state and parent snapshot.

### `child(config, on?)`

Creates a state node that owns one statically declared child machine while active.

| Field | Description |
| --- | --- |
| `name` | Required stable child invocation name. |
| `description` | Optional authored metadata. |
| `definition` | Child `MachineDefinition`. |
| `input` | Maps the narrowed parent state to child input. |
| `forward` | Optional partial parent-event map. Defaults to no forwarded events. |
| `onComplete` | Transition or guarded outcome for the child's inferred final-state union. |
| `on` | Optional second-argument parent event handlers while the child is active. |

A parent event cannot appear in both `forward` and `on` for the same child node. A forwarded target
must exist in the child's event schema.

### `final(options?)`

Creates a final node at its definition key. `options.description` supplies optional metadata.
Committing its state completes the machine with that state value. The union of all final keys
determines `MachineCompletion<Definition>`.

### `define(config, states)`

Creates the immutable `MachineDefinition`.

| Field | Description |
| --- | --- |
| `id` | Stable machine identifier. |
| `description` | Optional machine metadata. |
| `initial` | Pure function from decoded input to a state value. |
| `states` | Exhaustive record with exactly one constructor result for every state Schema tag. |

`define` throws `MachineDefinitionDefect` synchronously for missing or extra state keys, missing
targets, invalid guard fallback order, empty authored names, invalid child forwarding, invalid lane
concurrency, empty region slots, and other structural inconsistencies. TypeScript rejects incomplete
region trees and cross-slot targets. An initial state whose
tag has no node is detected by `Machine.run` because `initial` is evaluated with runtime input.

The deprecated `make` and tag-bearing constructor overloads remain compatibility adapters for
array-based definitions. New definitions use `define` and keyed tagless constructors.

## Event handlers

An event-handler record is keyed by event tag. Each entry has one of four shapes.

### Direct transition

```ts
{
  target: "Active",
  description: "Begin work.",
  reduce: ({ event }) => ({ id: event.id }),
}
```

`reduce` is synchronous and returns the destination variant's fields without `_tag`. The runtime
assigns the declared `target` and validates the complete state value.

### Guarded transition

```ts
{
  branches: [
    { when: namedGuard, target: "Accepted", reduce: () => ({}) },
    { otherwise: true, target: "Rejected", reduce: () => ({}) },
  ],
}
```

Branches are evaluated in array order. An `otherwise` branch is optional and must be last. No
matching branch is a `ProtocolDefect` at runtime.

### Ignored event

```ts
{ ignore: { description: "No state change is required." } }
```

An ignored handler accepts the event, commits no state, and emits `EventIgnored`.

### Stay update

```ts
{ stay: ({ state, event }) => ({ count: state.count + event.amount }) }
```

A stay merges fields into the active state without exit or entry. State-owned work and timers
continue. A direct transition targeting the current tag performs exit and re-entry instead.

## Outcome handlers

`onSuccess`, `onFailure`, and child `onComplete` accept a direct transition or guarded `branches`.
Reducers receive the narrowed current `state` plus:

| Handler | Additional field |
| --- | --- |
| `onSuccess` | `value`, the invoked Effect output. `race` supplies `winner` and `value`. |
| `onFailure` | `error`, the invoked Effect, task lane, or retry Schedule typed error. |
| `onComplete` | `value`, a child final-state value. |

Outcome guard order and fallback behavior match event guards.

## Definition types

| Type | Description |
| --- | --- |
| `MachineDefinition` | Full schema-bound definition returned by `define`. |
| `DefinitionMetadata` | Erased, synchronously inspectable definition shape consumed by graph tooling. |
| `MachineInput<D>` | Decoded input type of definition `D`. |
| `MachineState<D>` | Decoded state union of definition `D`. |
| `MachineEvent<D>` | Decoded event union of definition `D`. |
| `MachineCompletion<D>` | State variants whose tags are declared as final nodes. |
| `MachineRequirements<D>` | Union inferred from top-level work, region work, retry schedules, and child machines. |

The module also exports structural node and transition types used in these signatures, including
`StateNode`, `InvokeNode`, `ChildNode`, `FinalNode`, `Transition`,
`GuardedTransition`, `IgnoredTransition`, `SuccessTransition`, `FailureTransition`, `RetryPolicy`,
`NamedGuard`, and `ChildForwarders`.
