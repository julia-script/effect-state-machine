## `Machine.run`

```ts
import { pipe } from "effect/Function"

Machine.run(definition, input)
pipe(definition, Machine.run(input))
```

Returns a scoped `Effect` that creates a `MachineHandle`. `run` is dual: the first form is
data-first, and the second is data-last for an Effect-style pipeline.

| Input | Description |
| --- | --- |
| `definition` | A `MachineDefinition`. |
| `input` | The decoded type of `definition.schemas.input`. |

The Effect error channel is `never`. Its requirements are `Scope.Scope` plus the requirements
inferred from invoked Effects, retry Schedules, and child machines.

`run` calls the definition's pure `initial` function. If the returned state tag has no node, the
Effect dies with `MachineDefinitionDefect` before returning a handle.

## `MachineHandle`

| Member | Type | Behavior |
| --- | --- | --- |
| `snapshot` | `Effect<State>` | Reads the current committed state. |
| `changes` | `Stream<State>` | Emits the current state on subscription, then each committed state. Ends on completion or defect. |
| `send(event)` | `Effect<void>` | Enqueues an event and waits for its processing or machine termination. |
| `can(event)` | `Effect<boolean>` | Evaluates whether the live state accepts the event without changing state. |
| `completion` | `Effect<Completion>` | Waits for a declared final state. Preserves termination defects in its Cause. |
| `inspection` | `Stream<InspectionEvent>` | Emits metadata-only lifecycle and decision records. |
| `inspect(projectEvent)` | `Stream<ProjectedInspectionEvent<D>>` | Adds locally projected details to `EventReceived` records. |

Events passed directly to `send` and `can` are decoded values. Use `decodeEvent` at untrusted
boundaries.

### Event processing

One unbounded queue serializes external events, work and timer outcomes, region completions, and
child completions.
`send` waits until the selected transition or ignore has been processed. Concurrent senders are
ordered by queue arrival.

A globally known event that has no handler in the live state dies with `ProtocolDefect`. A guarded
handler with no matching branch and no fallback has the same result. After completion or defect,
pending and subsequent sends terminate with the machine's terminal outcome.

### State-owned work

Entering an invocation state starts its Effect or named task lanes. Entering a timed state starts
its timer. Entering a region-bearing state starts owned behavior in every active child. Entering a
child state starts the child machine. Leaving an owner interrupts its work and timers before the
new owner becomes active. An asynchronous result from an older state or region generation cannot
commit a transition.

Typed invocation failures follow `onFailure`. Effect defects terminate the machine and remain in
the Cause of `completion`. A child defect terminates its parent.

Region children receive events before their parent fallback. All responding parallel children are
selected against the same pre-event parent snapshot and commit together as one macrostep.

## Encoding and decoding

All helpers return Effects produced by the corresponding Effect Schema codec.

| Function | Input | Result |
| --- | --- | --- |
| `decodeInput(definition, unknown)` | Unknown boundary input | Decoded machine input. |
| `encodeInput(definition, input)` | Decoded machine input | Encoded input representation. |
| `decodeState(definition, unknown)` | Unknown boundary state | Decoded machine state. |
| `encodeState(definition, state)` | Decoded machine state | Encoded state representation. |
| `decodeEvent(definition, unknown)` | Unknown boundary event | Decoded machine event. |
| `encodeEvent(definition, event)` | Decoded machine event | Encoded event representation. |

Codec failures and requirements are those of the supplied Schema.

```ts
const decoded = yield* Machine.decodeEvent(definition, requestBody)
yield* handle.send(decoded)
```

Encoding state does not imply persistence or resumability. V0 provides no API for restoring a
machine instance or interrupted Effect from encoded state.

## Inspection events

`inspection` can emit the following tags:

| Tag | Meaning |
| --- | --- |
| `MachineStarted` | The initial state was committed. |
| `EventReceived` | A machine event reached the live state. |
| `TransitionSelected` | A direct, guarded, outcome, timer, completion, or region transition was selected. Region selections include owner path and macrostep identity. |
| `EventIgnored` | An explicitly ignored event was accepted. |
| `StateChanged` | A new state was committed. |
| `InvocationStarted` | State-owned Effect execution began. |
| `InvocationRetryScheduled` | A retry Schedule accepted a typed failure and produced a delay. |
| `InvocationSucceeded` | The invoked Effect produced a value and selected an outcome. |
| `InvocationFailed` | The invoked Effect's typed failure selected an outcome. |
| `InvocationCancelled` | The machine left the invocation state before completion. |
| `InvocationDefected` | The invoked Effect died. |
| `TimerStarted` | An entry-owned timer began. |
| `TimerFired` | The active timer elapsed and selected its transition. |
| `TimerCancelled` | Its owning entry exited before the timer fired. |
| `StaleOutcomeIgnored` | Work, timer, or completion from an inactive generation was discarded. |
| `ChildStarted` | A child instance began with a generated instance ID. |
| `ChildEventForwarded` | A declared parent event was mapped into a child event. |
| `ChildCompleted` | The child reached a final state and selected a parent outcome. |
| `ChildCancelled` | The parent left the child state before completion. |
| `ChildDefected` | The child died. |
| `MachineCompleted` | A declared final state completed the machine. |
| `MachineDefected` | Event protocol handling terminated the machine. |

Inspection records contain authored names, tags, branch metadata, owner paths, work kinds and lane
names, macrostep and generation identity, timer durations, generated child identity, and retry
timing. They exclude state values, Effect outputs, typed errors, defects, and event payloads by
default.

## Defect classes

### `MachineDefinitionDefect`

An `Error` subclass representing a structurally invalid definition. Construction-time checks throw
it synchronously. Runtime validation of the computed initial tag dies with it.

### `ProtocolDefect`

An `Error` subclass with `machineId`, `stateTag`, and `eventTag` fields. It represents a known event
that the live state does not accept, including a guarded handler for which no branch matches.
